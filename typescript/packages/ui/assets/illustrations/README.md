# Production identity derivatives

The six `*-216.webp` files are alpha-preserving derivatives of the transparent
masters in `../mascots/transparent/`. That directory records extraction method
and source/output hashes; original generation provenance remains in
`../mascots/GENERATION.md` beside the unchanged originals.

216×216, WebP quality 92, Pillow Lanczos resampling and method 6. These supply up
to 3× pixels for the current 72px identity display. No generative edit or baked
light/dark background is used. The default is the supplied retriever;
all six are available through the typed `Mascot` character prop and the same staging path. Normal composition keeps
the artwork usable on both light and dark surfaces.

Production staging copies WebP derivatives, not full-size PNG masters.
