# Selected mascot assets

The selected golden dog-blob original and its five breed variations:

- 01-retriever.png (default; requester-supplied recovered original)
- 02-bichon.png
- 03-corgi.png
- 04-dachshund.png
- 05-husky.png
- 06-border-collie.png

Original generated files are retained without resampling. These are reference
illustrations, not vector source files or an expression/motion library.
Visual usage and design context are documented only in root DESIGN.md.
Exact generation prompts, the source-verified model identifier and file hashes
are recorded in [GENERATION.md](GENERATION.md).

All six have transparent masters, 216px production WebPs and matching browser /
home-screen icon sets. See [icon generation](../icons/README.md).
