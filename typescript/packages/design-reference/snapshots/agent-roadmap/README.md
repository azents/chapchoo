## Status and limits

These are **Concept mocks**, not current application screenshots or component
renders. The historical computer-first direction and identity/team/management
studies are preserved as records, without reconstructing approval for every state.
The scoped Codex creation additions are an active **unconfirmed proposal**; they do
not approve local Computer/connector support, persona selection or other harnesses.
Controls are illustrative; no account authentication, persistence, permissions,
resource provisioning or Agent execution is implemented.

Desktop captures use 1440 × 1000 CSS px; mobile uses 390 × 844, DPR 1, Korean locale,
light and reduced motion. Long documents retain their content. Original responsive
CSS is retained, but unreviewed widths and native platforms are not verified.
Some source-network renders used an OS Korean fallback even when font loading
reported ready; these dumps include the declared Pretendard subsets. Pixel identity
to those fallback-font PNGs is not claimed. Native controls and transient focus can
also differ. This import preserves the DOM, content and declared styling rather
than redrawing or updating the concepts to current components.

Assets are shared in `assets/`, content-hashed and limited to this collection's
text/artwork. See [licenses](../ASSETS.md) and [archive rules](../AGENTS.md).
