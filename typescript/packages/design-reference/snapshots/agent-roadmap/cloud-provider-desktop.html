서버 제공 클라우드 준비하기

운영자만 등록·관리합니다. 사용자는 에이전트를 만들 때 제공 가능한 클라우드만 선택합니다.

1. 클라우드 등록

서버 전체 제공 Kubernetes

사용자의 컴퓨터 선택 목록에도 이 이름을 사용합니다.

종류·제공 범위는 이번 MVP에서 고정합니다. 팀·개인 범위나 Codex 계정은 여기서 선택하지 않습니다.

등록만으로 사용자에게 제공되지 않습니다.

2. 설치·연결 안내

찹츄 기본 클라우드

등록한 클라우드와 연결될 실행 환경을 준비합니다.

설치 안내 영역

운영자가 Kubernetes 환경에 연결 컴포넌트를 설치·실행합니다.

실제 설치 명령·연결 자격증명 발급 방식은 기술 설계에서 확정합니다.
연결 상태연결됨

관리 연결이 확인됐어요. 컴퓨터 생성 가능 여부도 별도로 확인합니다.

화면을 닫아도 등록은 유지됩니다. 목록으로 돌아왔다가 같은 클라우드의 연결 안내를 다시 열 수 있습니다.

3. 상태·제공 관리

제공 범위 · 서버 전체

관리 연결연결됨
컴퓨터 생성가능

운영자 별도 허용 제어는 제안 · 기본 꺼짐

사용자에게 제공하지 않음 · 새 에이전트 생성 허용을 켜야 합니다.

이번에 정할 정책: 연결되면 바로 제공할까요?

권장안: 운영자가 ‘새 에이전트 생성 허용’을 켜고 연결·생성 가능 조건이 충족될 때만 제공합니다. 잠시 꺼도 기존 에이전트·컴퓨터와 백그라운드 정리는 중단하지 않습니다.
더 작은 대안: 별도 허용 제어 없이 연결·생성 가능 상태가 되면 즉시 사용자에게 제공합니다.

설치 방법·자격증명은 설명용 빈 영역이며 실제 값이 없습니다. 상태·허용 변경은 mock입니다. HO 연결 상태와 각 HP의 컴퓨터 연결 상태는 별개이며, 클라우드 연결 단절이 기존 컴퓨터의 꺼짐을 의미하지 않습니다.
