# Archived static assets

Assets are local to each study's `assets/` directory and named by SHA-256 of the
captured bytes. They are retained for independent replay, not maintained copies.

- **Pretendard**: captured font subsets used by the original studies. Copyright
  2021 Kil Hyung-jin; SIL Open Font License 1.1. See
  [the retained license](licenses/Pretendard-OFL.txt) and
  [upstream](https://github.com/orioncactus/pretendard).
- **Lobe Icons**: original Codex/OpenAI/Claude visual marks used in the historical
  concepts, copied as static SVGs. MIT license; see
  [the retained license](licenses/Lobe-Icons-MIT.txt) and
  [upstream](https://github.com/lobehub/lobe-icons). Brand names and marks remain
  their respective owners' property; this archive does not claim endorsement.
- **Chapchoo illustrations**: existing project WebP character assets, originally
  referenced from pinned repository content. They retain the repository's license
  and [original asset provenance](../../ui/assets/illustrations/README.md).
- **Inline SVG interface shapes and styles**: part of the historical concept
  documents. No third-party JavaScript library is included in the dump.

Copied font/license content is preserved as distributed; prose and Korean sample
labels in the historical concepts are visual review data, not real account data.
