# Chat record inspection design

Frozen visual direction confirmed on November 12, 2026 (KST), captured from the
reviewed real-component draft with fictional retained records. Implementation,
executable behavior and deployment are separate from this archive.

- [Mobile record list](mobile-records.html): 402 × 780, Korean, dark, DPR 1.
- [Desktop expanded command](desktop-command.html): 1280 × 780, Korean, dark, DPR 1.

The confirmed scope is chronological independent one-line rows, left chevrons and
ACP-kind icons, plain opening previews, stable summary geometry, expanded details,
a full left collapse gutter with a dashed guide, fixed Sheet chrome and native
body scrolling. Full history has no top fade; Activity's continuation fade is
separate. The main conversation remains its own reading surface.

These script-free DOM/CSS dumps replay independently with local font/art assets;
controls are illustrative, not functional pagination, clipboard or execution.
The command result and counts are fictional design data, not facts derived by
production renderers. The production implementation must use retained typed
content and preserve unknown/raw fields without fabricating results.

Both pages were replayed with scripts disabled and external requests blocked,
then visually inspected at their recorded native viewport sizes. Other responsive
widths are not certified by these captures. Font licenses are included in assets.
The archive has two HTML states, thirteen shared assets, two font licenses and
this README (18 files, approximately 1.2 MiB); verification PNGs are not tracked.
These pages are not imported into Storybook or production and are not maintained
against later component changes.
