# Visual design authority

- Read root `DESIGN.md` when present and the relevant linked references before UI edits.
- Author visual guidance using [the DESIGN.md guide](../../../typescript/packages/design-reference/DESIGN_AUTHORING.md): specific intent, semantic token values, usage, platform differences and review status.
- Update prose, tokens and rendered examples together when their design changes; keep one canonical value source.
- Visual approval does not approve sample features, production promotion or technical architecture. Preserve existing ownership and immutable Requirements/ADR/Design records.
