# Content-first mobile density

- Put conversation identity above content at the upper left; let the body/results span available width instead of reserving an empty avatar column.
- Reduce redundant copy, excessive padding and oversized decoration before reducing text size. Reflow essential status/actions rather than silently dropping them.
- Preserve readable text, text enlargement, visible focus and usable touch targets. Compact visual treatment can have a larger non-overlapping hit area.
- Review narrow, long-content and enlarged-text states using [the design quality checklist](../../../typescript/packages/design-reference/DESIGN_AUTHORING.md#quality-principles).
