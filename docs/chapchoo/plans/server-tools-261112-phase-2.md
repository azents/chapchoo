## Fixed interfaces and limits

- Authoritative Protobuf adds a separate component catalog service and bounded bidirectional invocation: one sealed Submit, optionally cancellation of that call only; Waiting/Started/Final responses. No second Submit, retargeting, arbitrary cancellation handle, stream resume or polling.
- Scope is established from trusted product Agent/conversation/execution and native-owner provision before any native ID exists. Local capabilities contain no server credential; setup uses headers, never URL/model arguments/environment logging. Reconnect/key refresh updates server call credentials without rebinding local access. Native retirement invalidates access.
- Discovery, dispatch, domain commit and protected final disclosure revalidate current authority. Native readiness/IDs/current UI selection are not tool authorization factors. Publication uses phase 1's completed Store operation and returns a structured object with `message_id` plus an acceptance text result, never the whole message body.
- Public MCP SDK Streamable HTTP APIs and public typed cancellation/session hooks only. Initially negotiate the approved 2025-06-18 profile through native's default initialization. Verify the effective reserved `chapchoo` endpoint/catalog and reject collisions; no silent replacement/downgrade/restart.
- Retain Design bounds: 64-KiB internal messages; 48-KiB arguments/results/catalog (at most 32 definitions); 16 executing; 128 waiting/8 MiB global; 8 waiting/512 KiB per trusted Agent; fair Agent dispatch/FIFO within each partition; 10-second queue and 50-second total response waits; at most Waiting/Started/Final buffering. Started work retains its owner/capacity after observer timeout/loss.
- Local HTTP bounds apply before header/body parsing, including unauthenticated input: 128 accepted connections, 128 active requests/8 MiB retained payload, 64-KiB bodies, 16-KiB headers, 10-second header/body read deadlines. At most four protocol sessions per native-owner capability. Host/Origin and capability checks are independent; no durable event replay.
- Existing graceful 20-second/forced five-second cleanup remains the composition boundary. Waiting cancellation/expiry/shutdown arbitrates against dispatch; dispatch winners preserve honest possible/known effects, with no recall guarantee for chat writes.
